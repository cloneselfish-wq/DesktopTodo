# DesktopTodo 桌面待办

一款 Windows 桌面待办清单（To-Do List）小组件：可置顶悬浮、也可真正"贴"在桌面上，支持开机自启、勾选划掉动画、划掉后可找回、截止日期排序。基于 .NET Framework 4.8 (WPF) 编写，**编译零依赖**——无需安装运行库、Node.js 或任何包管理器。

## 功能特性

- **桌面小组件形态**
  - 无边框小窗口，默认窗口置顶（📌 可切换）
  - 托盘菜单"贴入桌面(壁纸层)"：将窗口真正嵌入桌面层（位于桌面图标之下、壁纸之上），像桌面小工具一样
  - 位置记忆：重启后回到上次的摆放位置
- **待办管理**
  - 输入待办后回车或点击"＋ 添加"即可新增
  - 截止日期为可选项，支持日期选择器
  - 勾选待办：一道横线划过文字的划掉动画，随后卡片淡出收起；数据即时保存，中途关闭程序也不会丢失
  - **划掉≠删除**：底部"已划掉 (N)"展开区列出所有已勾选项，点击"↺"即可恢复到待办列表
  - 每条待办记录**创建时间**与**划掉时间**
- **智能排序**
  - 有截止日期的按日期升序排列（过期红色提醒"已过期"、当天橙色"今天截止"）
  - 无截止日期的保持默认顺序（新建的在前），排在有截止日期的条目下方
- **系统集成**
  - 系统托盘：显示/隐藏、窗口置顶、贴入桌面、开机自启开关、退出
  - 关闭按钮仅隐藏到托盘，双击托盘图标可再次打开
  - 开机自启通过写入当前用户注册表 Run 键实现（无管理员权限要求）
- **数据本地化**
  - 所有数据保存在本地 `%APPDATA%\DesktopTodo\todos.json`，不上传任何数据

## 环境要求

- Windows 10 (1903+) / Windows 11
- .NET Framework 4.8（系统自带，无需额外安装）

## 构建与运行

```powershell
# 构建（使用系统自带 csc.exe 编译，自动解析 GAC 引用）
powershell -ExecutionPolicy Bypass -File build.ps1

# 运行
.\DesktopTodo.exe
```

无需 Visual Studio、无需 NuGet 还原。

## 使用说明

1. 启动后窗口出现在屏幕右下角，默认置顶显示，可拖动标题栏移动位置
2. 在顶部输入框输入待办，可选择截止日期，回车或点击"＋ 添加"
3. 点击条目前方的圆圈即可勾选：横线划掉动画后该条从列表消失，进入底部"已划掉"区
4. 点击"已划掉 (N)"展开，点击"↺"恢复任意一条
5. 点击📌切换窗口置顶；右键托盘图标可使用全部功能（含"贴入桌面(壁纸层)"与"开机自动启动"）
6. 彻底退出请使用托盘菜单中的"退出"

## 项目结构

```
DesktopTodo/
├── build.ps1                # 一键构建脚本（系统自带 csc.exe，无外部依赖）
└── src/
    ├── Program.cs           # 入口、单实例互斥锁、全局异常处理
    ├── Data.cs              # TodoItem/Settings 数据模型、JSON 持久化、排序逻辑
    ├── AutoStart.cs         # 开机自启（HKCU Run 注册表）
    ├── DesktopHost.cs       # 贴入桌面壁纸层（Progman/WorkerW technique）
    ├── TrayController.cs    # 托盘图标与菜单
    ├── MainWindow.cs        # 主窗口、标题栏、添加面板、置顶/嵌入/位置记忆
    └── MainWindow.Items.cs  # 待办卡片、划掉动画、"已划掉"区与恢复
```

## 技术说明

- 纯 C# 代码构建 WPF 界面（未使用 XAML），兼容系统自带 csc.exe 的 C# 5 语法
- "贴入桌面"通过向 Progman 发送 `0x052C` 消息生成 WorkerW 壁纸层，并将窗口 `SetParent` 至该层实现
- 划掉动画使用 WPF `DoubleAnimation`/`ThicknessAnimation`：横线为 `ScaleTransform.ScaleX` 0→1，随后透明度与高度收起
- 若 `gh`/Git 凭据失效不影响应用本身，所有功能均为本地实现，无任何网络请求
